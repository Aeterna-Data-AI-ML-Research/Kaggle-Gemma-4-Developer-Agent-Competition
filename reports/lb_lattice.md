# Appendix: public leaderboard lattice

Assuming 58 public tasks and truncation to two decimals:

| Public score | Implied solved |
| ---: | ---: |
| 0.06 | 4 / 58 |
| 0.10 | 6 / 58 |
| 0.13 | 8 / 58 |
| 0.17 | 10 / 58 |
| 0.18 | 11 / 58 |
| 0.20 | 12 / 58 |
| 0.22 | 13 / 58 |
| 0.24 | 14 / 58 |
| 0.29 | 17 / 58 |

A one-task swing moves the displayed score by about 0.017. Offline calib rates near
31% do not map 1:1 onto this lattice because the public set, sampling noise, and
strict-submit rules differ.
