# Supporting research archive

This folder restores the **evidence-backing research markdown and phase reports**
that led to [`PAPER.md`](../PAPER.md). The compact episode packs in `../evidence/`
are the primary reproducible data; these documents explain *how* those claims
were formed along the way.

## Layout

| Path | Contents |
| --- | --- |
| `reports/` | Final retrospective draft, task research matrices, failure reports |
| `phase_reports/` | Phase 1/2/3 analysis markdown + summary JSON |
| `overnight/` | Overnight breakthrough / ForgeSWE campaign notes |
| `plans/` | Evaluation and training plans (incl. P749) |
| `audits/` | Architecture / handoff audits |
| `ledgers/` | Master findings ledger |
| `protocols/` | Virtual-clock / agent-dev protocol snapshots |

## Not included (intentionally)

- `PROPRIETARY_PLAYBOOK.md`, full ops `experiment_log.md`
- Adapter weights, vault zips, raw episode tool traces
- Cloud credentials / SSH / fleet provision files

See also [`reports/RESEARCH.md`](../reports/RESEARCH.md) for the ticket ↔ public-name map.
